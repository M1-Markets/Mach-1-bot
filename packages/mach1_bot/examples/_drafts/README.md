# Drafts

These examples are work-in-progress and unmaintained. They contain a mix of working code and TODO stubs for features that aren't implemented yet (DCA, grid trading, AI helpers, advanced order types, Monaco direct SDK access).

For working examples, see the parent directory:

- `../quickstart.ts` — minimal setup, single sim buy
- `../with-strategy.ts` — adds a strategy callback
- `../with-backtest.ts` — runs a basic backtest

These files are preserved for reference and may be promoted back as their underlying features ship.
